# Björnrike Afterski

Friendslop-partyspel inspirerat av den årliga skidresan till Björnrike. Spela på mobil eller dator.

**Spela:** https://bobsvamp1.github.io/BJ-RNRIKE/

- 2–8 spelare, var och en på sin egen mobil. En skapar ett rum, resten skriver in koden.
- 50 minispel, 7 slumpas fram per kväll. Etta 3 p, tvåa 2 p, trea 1 p. Kaoshjul, snöbollar och straffklunkar.
- Vissa spel använder mikrofon, kamera eller rörelsesensor. Saknas de finns en knapp istället.
- Testläge mot bottar funkar utan internet.

Onlineläget går via PeerJS (gratis signalserver). Inget konto behövs.
